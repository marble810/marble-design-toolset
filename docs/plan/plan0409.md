# UI框架与组件设计相关需求
1. 去除所有tailwindcss依赖，不使用css库
2. 使用bits-ui作为无头UI库，我将重头对该项目的样式进行设计
   - https://bits-ui.com/docs/llms 阅读该docs，获取llms.txt作为设计bits ui相关内容时的基准指南，写入到agents.md
3. 将自定义组件放置到统一文件夹/子文件夹结构中统一管理
4. 本项目会被设计成Pixel Art的UI美术风格，因此，fontsize margin padding gap等尺寸会使用px作为单位，用户可以直接使用浏览器缩放进行缩放操作

# 响应式设计相关
1. 当media width小于720px时，直接用黑色填满屏幕，说明该应用最小分辨率宽度应大于720p
2. 不要过度设计响应式设计，不要考虑竖屏行为，写入agents.md：**该应用是纯横屏应用，不要过度设计响应式设计**

# 界面文案包装设计
1. 当前设计阶段**只设计英文**，写入到agents.md中
